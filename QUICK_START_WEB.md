# Masters Web — Быстрый старт

## ✅ Готово к использованию!

### Запуск приложения

**Самый простой способ:**
1. Найдите на **Рабочем столе** ярлык **"Masters Web"**
2. Дважды кликните по нему
3. Приложение автоматически откроется в браузере

**Альтернативный способ:**
1. Откройте папку `Masters`
2. Запустите файл `launch_masters.bat`

### ⏱️ Время запуска
- **Первый запуск:** ~2 минуты (автоматическая сборка)
- **Последующие запуски:** 2-3 секунды

### 🌐 Адрес приложения
После запуска приложение доступно по адресу:
```
http://localhost:8080
```

### 🛑 Остановка сервера
Закройте окно консоли с надписью "MASTERS WEB SERVER"

### 💾 Хранение данных
- Все данные хранятся локально в браузере (IndexedDB)
- Данные привязаны к браузеру и профилю
- Приложение работает полностью оффлайн

---

## 🔧 Решение проблем

### Приложение не открывается автоматически
Откройте браузер вручную и перейдите на `http://localhost:8080`

### Белый экран в браузере
1. Откройте консоль браузера (F12)
2. Проверьте вкладку Console на наличие ошибок
3. Перезапустите сервер

### Порт 8080 занят
Отредактируйте файл `launch_masters.bat`, замените `8080` на другой порт (например, `8081`)

### Ошибка при первой сборке
```bash
cd Masters
flutter pub get
flutter clean
flutter build web --release --no-web-resources-cdn
```

## 🎯 Особенности web-версии

### ✅ Что работает
- Полный функционал приложения
- База данных (IndexedDB)
- Экспорт/импорт данных
- Адаптивный интерфейс для больших экранов
- Работает оффлайн после загрузки

### ⚠️ Ограничения
- **Нет push-уведомлений** (ограничения браузера)
- **Нет фоновой работы** (браузер должен быть открыт)
- **Данные привязаны к браузеру** (не синхронизируются между устройствами)
- **Резервное копирование на Yandex.Disk работает через CORS** (может не работать)
