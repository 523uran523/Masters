## Цель
Выпустить релиз 0.4.1+24 с тремя фичами Э1 плана `2026-11-07-detailed-dev-plan.md`:
быстрый заказ, дублирование заказа, проактивный сигнал низкой маржи.

## Состав релиза

### Э1.1 Быстрый заказ («+ Заказ» на «Сегодня»)
- Кнопка «+» в навбаре «Сегодня» больше не открывает `JobFormScreen` (7 экранов).
- Вместо этого — `CupertinoModalPopup` с `_QuickOrderSheet` (высота ~380px, адаптивный к клавиатуре):
  1. **Клиент**: горизонтальный скролл чипов существующих клиентов + поле «новый клиент по имени».
  2. **Что делаем**: поле названия заказа.
  3. **Позиция + цена** (опционально): название работы + цена в ₸.
  4. Кнопка «Создать заказ».
- Блокировка «Нет клиентов» убрана — шит сам заводит клиента по имени.
- После создания — автопереход в карточку заказа (`JobDetailScreen`), где добавляются сроки и детали.

### Э1.2 «Дублировать заказ»
- В `NavigationBar` карточки заказа добавлена кнопка `CupertinoIcons.doc_on_doc` («Дублировать»).
- Стор: `duplicateJob(sourceJobId)` — создаёт новый заказ с теми же строками,
  копируя `price_cents` и `cost_at_order_cents` (снимок на момент дублирования).
- Новый заказ: статус `nuevo`, пустые даты, тот же клиент, название «{оригинал} (копия)».
- Автоматический `recalcJobTotals` синхронизирует обязательства.

### Э1.3 Проактивный сигнал низкой маржи
- Стор: `jobMarginRatio(jobId)` — доля маржи в цене (доход по строкам).
  `isLowMarginJob(jobId)` — `true`, если доля < 10% (`kLowMarginRatio = 0.10`).
  `lowMarginDoneJobs()` — список таких заказов со статусами done/closed.
- **«Сегодня»**: в списке заказов у низкомаржинальных появляется Pill «низкая маржа» (orange) рядом со статусом.
- **Карточка заказа**: после блока «Маржа» — Pill «низкая маржа» + ChipButton «Пересмотреть цены» → `CatalogScreen` с фильтром по названиям позиций заказа.
