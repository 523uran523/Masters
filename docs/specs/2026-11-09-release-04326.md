## Цель
Выпустить релиз 0.4.3+26 по этапу Э3 плана `2026-11-07-detailed-dev-plan.md`
(общее ТЗ §5.4, решение §12.4, UX §6.7): заявки (обращения до заказа) с

## Состав релиза

### Э3.1 Схема v24 (аддитивная)
- `leads` — id, name, phone, client_id (FK clients), source, request,
  budget_cents, status (`active`/`refused`/`converted`), next_step_at,
  close_reason, converted_job_id (FK jobs), note + sync/audit колонки.
- `quotes` — id, job_id (FK jobs), lead_id (FK leads), number, revision,
  total_cents, snapshot_json, pdf_path, valid_until, sent_at, status
  (`draft`/`sent`/`accepted`/`rejected`) + deleted_at.
- `jobs.lead_id` (FK leads) — заказ помнит, из какой заявки вырос.
- Порядок в `_createLeadsSchema` → `_ensureLeadsColumns`: таблица `leads`
  создаётся **до** колонки `jobs.lead_id` с FK, иначе `foreign_key_check`
  падает на полуреализованной связи.
- Миграция `oldVersion < 24` пересоздаёт триггеры (`_createAuditTriggers`,
  `_createSyncTriggers`), чтобы новые таблицы попадали и в `audit_log`, и в
  `sync_outbox`.
- `leads`/`quotes` добавлены в `kSyncedTables` (leads перед jobs),
  `kBackupTables`, `kAuditedTables`, `kMojibakeScanColumns`,
  `kTableDependencies`. `clearAll` чистит `quotes` раньше `jobs`, а `jobs`
  раньше `leads`.
- `AppDatabase.version = 24`.

### Э3.2 Модель и стор заявок
- `lib/data/models/lead.dart`: `isStaleAt(now)` / `daysOverdue(now)` —
  «зависание» считается в одном месте, экран и «Сегодня» не расходятся.
  Просрочка требует назначенного шага: заявка без `next_step_at` не «зависает».
- `lead_repository.dart` — `save` / `softDelete` / `getAll`.
- Стор: `leads`, `leadById`, `leadsByStatus`, `staleLeads()` (сортировка по
  давности просрочки), `staleLeadsCount`, `createLead`, `updateLead`,
  `closeLead(reason:)`, `convertLeadToJob` (создаёт клиента, если заявка была
  анонимная; переносит бюджет и срок; ставит `jobs.lead_id` и
  `converted_job_id`), `leadsFunnel()` (total/active/stale/converted/refused +
  bySource), `leadsConversionRate`, `deleteLead`.

### Э3.3 Экран «Заявки» (§6.7)
- `LeadsScreen`: сегменты `Активные | Зависшие | Отказ | Конверт.`, поиск по
  имени/телефону/запросу, Pill «зависшие: N» с переходом в сегмент.
- В «Активных» просроченные — наверху; Pill «просрочено N дн.» (orange/red).
- Карточка: «Создать заказ», «КП», «Напомнить» (share-sheet через
  `leadFollowUpText` из Э2), «Отказ» (с причиной).
- `LeadDetailScreen`: детали, кнопки действия, переход к клиенту
  (`ClientDetailScreen`) и к истории КП.
- `MoreScreen`: ListRow «Заявки и КП» с Pill зависших — под флагом.
- Флаг `module_leads` (`settings.leadsEnabled`, по умолчанию включён) +
  переключатель в настройках модулей.

### Э3.4 КП как неизменяемый снимок (§12.4)
- `saveQuoteSnapshot(jobId)` фиксирует номер (`КП-ГГГГ-NNN`), ревизию, итог и
  строки в `snapshot_json`. Дальнейшая правка заказа документ не меняет.
- `nextQuoteSlot` — серийный номер по году; новая ревизия того же номера
  (`reuseNumber`) увеличивает `revision`, счётчик ведётся отдельно от номера.
- `DocumentService.buildQuotePdf(quote)` рендерит PDF **только из
  `snapshot_json`** — ни одного обращения к заказу.
- `DocumentService.savePdfPath` теперь возвращает выбранный путь (был `bool`):
  путь кладётся на снимок, чтобы «Открыть PDF» открывал ровно тот файл,
  который уходил клиенту. На web возвращается `null` — там файл уходит через
  браузер.
- `QuotesScreen`: история ревизий, «Новая ревизия», «Открыть PDF», «Принято»,
  «Отправлено», удаление; подпись о том, что старые ревизии сохраняются.
- `job_detail_screen`: кнопка «КП» в секции «Действия» — открывает историю, а
  если снимков ещё нет, создаёт первый и сразу предлагает PDF.

## Риски и ограничения
- `min_supported_version_code` = 1, форс-обновления нет; v24 аддитивна,
  откат на 0.4.2 не трогает новые таблицы (просто игнорирует их).
- Заявка без назначенного шага в «Зависшие» не попадает — по замыслу требовать
  напоминания не о чем; UX-текст пустого сегмента это объясняет.
- PDF на web не сохраняет путь (`savePdfPath` → `null`): файл скачивается
  браузером, «Открыть PDF» там предложит пересохранить снимок.
- Витрина «Сегодня» про зависшие заявки пока не показывает — агрегатор Э9.
- `stale_leads_test` и `leads_funnel` тесты — в финальной тестовой задаче плана.
