## Цель
Выпустить релиз 0.4.2+25 по этапу Э2 плана `2026-11-07-detailed-dev-plan.md`
(общее ТЗ §5.3): напоминание об оплате через share-sheet и компактный
«Прогноз» на вкладке «Деньги».

## Состав релиза

### Э2.1 Share-sheet «Напомнить» (карточка долга и карточка заказа)
- Новый `lib/core/reminder_text.dart`:
  - `paymentReminderText(...)` — текст «{Имя}, добрый день! По вашему заказу
    «{название}» осталась доплата {сумма} до {дата}. [Если удобно, можете
    перевести на {метод}.] Спасибо!»; дата — `d MMMM yyyy` (ru), пустое имя →
    «друг», строка про метод оплаты только если метод задан (выдумывать
    реквизиты хуже, чем промолчать).
  - `leadFollowUpText(...)` — заготовлен под Э3 (напоминание по заявке),
    та же механика.
  - `shareReminderText(text)` → `ReminderShareResult {shared, copied, failed}`:
    `SharePlus.instance.share(ShareParams(text:))`, при исключении (web,
    эмулятор) — `Clipboard.setData` + алерт «Откройте мессенджер и вставьте»,
    при двойном отказе — «Не удалось».
- **Карточка долга** (`money_screen.dart`, `_obligationRow`): действие
  «Напомнить клиенту» вместо записи в сторовые напоминания теперь готовит
  текст (с `kPaymentMethods`) и отдаёт его системному share. Метод стора
  `createPaymentReminder` оставлен как public API.
- **Карточка заказа** (`job_detail_screen.dart`): ChipButton «Напомнить»
  (`paperplane`) в секции «Оплата» при остатке > 0; срок — дата обязательства,
  иначе срок заказа, иначе «через 7 дней».
- Никаких API мессенджеров — только системный share / буфер обмена.

### Э2.2 payment_method в UI оплаты
Закрыто раньше, в 0.4.0+23 (`showPaymentMethodPicker()`/`kPaymentMethods`
в `lib/app/ui.dart`, колонки в `money_transactions`/`obligations`). В этом
релизе изменений нет.

### Э2.3 Компактный «Прогноз»
- `_buildPlanSection` свёрнут: если в горизонте 6 недель есть разрыв —
  Pill (orange) «разрыв d MMM»; иначе одна строка «Запас N недель»
  (`N = plan.length ~/ 7`, cashPlan всегда отдаёт 42 дня); пустой план —
  «Прогноз пуст».
- Баланс/конечный баланс/дни событий из карточки убраны; ChipButton
  «Детали» (`list_bullet`) открывает модалку `_showCashPlanDetails`
  (высота 420px): остаток, дебиторка, кредиторка, прогноз, дни событий.
- Без разрыва вкладка «План» не занимает экран.
