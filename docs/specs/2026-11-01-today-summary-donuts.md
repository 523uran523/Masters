# ТЗ: Сводка на главном — кольцевые диаграммы (месяц + 7 дней) (today-summary-donuts)

Статус: **выдано** (junior)
Дата: 01.11.2026
Пользователь: «Сводка месяц и за 7 дней на главном экране сделай не текстом а круговыми диаграммами/графиком».

## Цель
На Today-экране (`lib/features/today/today_screen.dart`, блок `_buildMonthCard`, ≈стр. 847–949) заменить текстовые строки «Сводка месяца» на **два кольцевых (donut) графика**: период «Месяц» и период «7 дней». Текст оставить в минимальном виде (легенда-значения), основная подача — графики.

## Входит
1. **Данные** (всё считать в today_screen, как сейчас считается месяц, без новых store-методов):
   - «Месяц»: как сейчас (`createdAt` в текущем году/месяце, `!voided`).
   - «7 дней»: `createdAt` ≥ начало дня (now − 6 суток), `!voided`.
   - Для каждого периода: `income`, `expense`, `profit = income − expense − taxReserve` (налоговый резерв только для месяца — как сейчас; для 7 дней profit = income − expense).
2. **UI — два donut'а рядом в одной карточке** (AppCard, заголовок «Сводка»):
   - Общий виджёт-кольцо (написать новый, заменить `_MonthPiePainter`): ring (толщина ≈ 0.25–0.3 радиуса), сегменты: Доходы (зелёный `colors.green`/0xFF34C759) и Расходы (красный `colors.red`/0xFFFF3B30) по долям от `income+expense`; в центре — прибыль: `+$X`/`−$X` (формат `_money`), цвет зелёный/красный по знаку. Если данных нет (income+expense=0) — нейтральное пустое кольцо (цвет separator) + в центре «—».
   - Под каждым кольцом подпись периода: «Месяц» / «7 дней».
   - Текст-строки `_moneyRow` (На счетах/Доходы/Расходы/Прибыль) **удалить**; под графиками — компактная строка-легенда: «Доходы / Расходы» с точками-цвeтами, и значения за оба периода (например, две строки: «Месяц: Д X · Р Y · Прибыль Z» и «7 дней: …» — компактно, 12px, secondaryLabel). Пользователь сказал «не текстом» — график основной, легенда минимальная (значения должны быть где-то видимы).
   - Тап по карточке (или по каждому кольцу) → `StatsScreen` — сохранить (как сейчас, существующий `Navigator.push` в ≈стр. 882–884).
   - Старый 56px-«пирожок» в углу заголовка убрать (заменён графиками).
3. **Краевые случаи**: пустой период → нейтральное кольцо + «—»; только доходы или только расходы → сегмент на 360°; отрицательная прибыль → красный текст в центре; длинные суммы — формат `_money` (сокращения по существующему).
