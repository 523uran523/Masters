# ТЗ: Главная/Today v2 (таймер дня, быстрые ₽, сводка месяца + пирограмма)

Статус: **не выпущено** (ждёт: Б0 + Б1; правит today_screen, stats_screen, settings_controller/screen, masters_store, DB)
Дата: 31.10.2026
Пользовательские заметки: №3, 4, 7, 20, 22.

## Цель
Главный экран (Today) — «рабочий пульт»: запустить/остановить рабочий день, быстро провести доход/расход, увидеть месячную сводку и мини-графики, которые ведут в Аналитику.

## Входит

### А. Таймер рабочего дня (замечание №7)
- На Today — блок «Рабочий день»: кнопка Play (старт) → выбор, к чему привязать: открытый заказ (список) или «без заказа». Стоп — пауза. За день включений много.
- В настройках — «Ставка за час» (копейки) — глобальная, с пометкой, что её не надо вводить заново. (Ключ `hour_rate_cents` в SettingsController, секция настроек «Заказы»/общая.)
- DB v16 (после v15 из calculator-v2): таблица `work_sessions(id, job_id NULL, started_at, paused_seconds INTEGER)`; активная сессия = незавершённая. Завершение — кнопкой или при открытии нового дня (авто-закрытие ночью, senior решит).
- На Today: «Сегодня: 2 ч 15 м (3 включения)» + по заказу: в карточке/детале заказа — сумма наработанных часов за день, если ставка задана — «≈ X ₽» (часы × ставка).

### Б. Быстрый доход/расход (замечание №3)
- Одна компактная кнопка «₽» (или «Быстрые деньги») в верхнем блоке Today → CupertinoActionSheet: «Продажа / Доход», «Расход», (опц. «Перевод между счётами» — не обязательно в этом слайсе).
- Далее одно окно: сумма → счёт (выпадающий) → готово. Повторить методы masters_store (те же, что у Быстрой продажи в Деньгах — единая логика).

### В. Сводка месяца + кликабельная мини-пирограмма (замечания №4, 22)
- Карточка на Today: «Месяц: Деньги на счетах / Доходы / Расходы / Прибыль (с учётом налогового резерва по taxRate)». Крупные аккуратные числа, не вылезает.
- Мини-пирограмма (Canvas, без новых зависимостей: 2–3 сектора доход/расход/прибыль, или расход-доля) — тап → Stats.
- Stats: фикс переполнений текста (FittedBox/TextOverflow, проверка длинных кириллических подписей — замечание №20); структуру Stats не трогаем в этом слайсе (реорганизация — отдельный слайс при необходимости).

## Не входит
- Календарный вид / объединение с записями (Б6).
- Печать часовых наработок.

## Критерии приёмки
- Play/Stop работает много раз за день; сессии привязываются к заказу; ставка вводится один раз.
- «₽» на Today создаёт транзакцию без входа в раздел Деньги.
- Карточка месяца + пирограмма; тап открывает Stats; ни один текст не вылезает (проверить на длинных названиях категорий/счетов).
- DB v16; analyze 0 ошибок; тесты (sessions CRUD, сводка месяца) зелёные.
