# ТЗ: Калькулятор состава и себестоимости товаров (Inventory Composition)

Статус: **выдано** (senior)
Дата: 01.11.2026

## Цель
Реализовать механизм «рецептов» (состава) для товаров на складе. Вместо простой ручной цены, стоимость товара может складываться из компонентов (другие товары со склада, материалы) и ручного труда. При открытии товара пользователь должен видеть детальный расчет его себестоимости.

## Входит
### А. Данные и БД (v18)
- `lib/data/app_database.dart`: Новая таблица `inventory_compositions(id INTEGER PRIMARY KEY, itemId TEXT, componentId TEXT NULL, isLabor BOOLEAN, qty REAL, price_cents INTEGER, note TEXT)`.
- Миграция: поднять версию до **v18**.
- `masters_store.dart`:
  - `saveItemComposition(itemId, List<CompositionItem>)` — сохранение состава.
  - `getItemComposition(itemId)` — получение состава.
  - `calculateItemCost(itemId)` — агрегация суммы всех компонентов.
  - Связь с существующим `InventoryItem`: при сохранении состава, итоговая сумма автоматически обновляет `cost_cents` самого товара.

### Б. UI: Редактор состава (на базе Cost Calculator)
- В деталях товара (`inventory_detail_screen.dart`) добавить кнопку «Рассчитать себестоимость» $\rightarrow$ открытие экрана, похожего на `cost_calculator_screen.dart`.
- Функционал редактора:
  - Добавление компонента: выбор товара со склада $\rightarrow$ подстановка его текущей цены.
  - Добавление «Ручного труда»: ввод суммы и описания (например, «Работа мастера»).
  - Изменение количества $\rightarrow$ пересчет итога.
  - Кнопка «Сохранить состав» $\rightarrow$ запись в БД + обновление цены товара.

### В. UI: Просмотр состава
- В деталях товара (сразу под ценой/себестоимостью) добавить компактный блок «Состав стоимости».
- Список: `Компонент (Кол-во) — Цена`. Итого: `Сумма`.
- Если состава нет — блок скрыт.

## Критерии приёмки
- Можно создать состав товара из других позиций склада и ручного труда.
- Итоговая стоимость товара пересчитывается автоматически при сохранении состава.
- В деталях товара виден детальный разбор цены (откуда взялась себестоимость).
- DB v18, analyze 0 ошибок, тесты (создание состава $\rightarrow$ проверка итоговой цены товара) зелёные.
- Commit `Add inventory cost composition (BOM)`, push (pull --rebase БЕЗ autostash).

## Запреты
- Не трогать функционал `unified-booking` (если он уже в репо) и `work_sessions` (v16).
- Не менять структуру `InventoryItem`, кроме обновления `cost_cents`.
