# ТЗ: Свеча кодировки — двойная CP1251 в jobs/job_detail (encoding-sweep)

Статус: **выдано** (senior)
Дата: 01.11.2026
Пользователь: «В карточках заказа и записи кодировка поехала, текст на русском не читается» + «Везде проверь кодировку, чтобы текст везде нормально читался».

## Диагноз (установлен архитектором)
`lib/features/jobs/jobs_screen.dart` и `lib/features/jobs/job_detail_screen.dart` содержат **двойную CP1251** кодировку: UTF-8 байты русского текста были прочитаны как CP1251 и записаны обратно как UTF-8. Признаки (по grep):
- `jobs_screen.dart`: строки 149, 180, 193, 279–287, 474, 491, 559, 644, 791–792, 822–825 — артефакты вида `тХи╨У`, `╨Ъ╨╗╨╕╨╡╨╜╤В` («Клиент»), `╨Ю╨Ъ` («ОК»), `тХи╨итФР…` и т.д. — быстрые подсказки, диалоги, заголовки карточек заказов. Именно они показываются в карточках/диалогах экрана Заказы/События.
- `job_detail_screen.dart`: строки 67–68, 97, 175, 178, 389, 539, 728, 736, 802, 854, 889, 927, 988, 1033–1034, 1042+ — `╨Ъ╨▓╨╕╤В╨░╨╜╤Ж╨╕╤П`, `╨Ф╨╛╨║╨╝╨╡╨╜╤В`, `тАв` и т.д.

Текущий `test/mojibake_scan_test.dart` зелёный, т.к. ловит только CP1252-сигнатуры (Рћ/С‚/Рє…). CP1251-сигнатуры (тХ, ╨, ╩, ╪, ╫, тА, тФ) не покрыты.

## Входит
1. Декодирование: для каждого найденного повреждённого string-literal `utf8.decode(cp1251.encode(покрытый))` → восстановление исходного русского текста. Проверять визуально: `тХи╨УтХитФВтХитХХ` → «Все», `╨Ъ╨╗╨╕╨╡╨╜╤В` → «Клиент», `╨Ю╨Ъ` → «ОК», `тАв` → «~» (стр. 927: «{дата} тАв {минуты}» → «{дата} ~ {минуты}» — по смыслу строки «н. времени по сегодня»).
2. Полный проход по `lib/**/*.dart` (grep-сигнатуры: `тХ`, `тА`, `тБ`, `тГ`, `тД`, `тЕ`, `тЖ`, `тФ`, `╨`, `╩`, `╪`, `╫`, `╬`, `╭`, `╮`, `╯`, `╰`, `№`, `Рћ`, `С‚`, `Рє`, `СЂ`, `Рѕ`, `Рё` — только в многобуквенных сочетаниях, без ложных срабатываний на одиночные русские буквы). Все найденные повреждения исправить (включая те, что не в jobs/job_detail).
3. Расширить `test/mojibake_scan_test.dart`: добавить CP1251-сигнатуры к текущим CP1252 (паттерны-сочетания: `тХи|тАв|тФ[аеёу]|╨[А-я]|╩[А-я]|╪[А-я]|Рћ|С‚[аеё]|Рє[аеё]|СЂ[аеё]` — подобрать минимально надёжный набор без FP), сканировать `lib/**/*.dart`. Тест должен ПРОВАЛИВАТЬСЯ на текущем коде и ПРОХОДИТЬ после фикса.
4. Проверка: `flutter analyze --no-pub` 0 ошибок; `flutter test` все зелёные; `dart format` затронутых.

## Не входит / запреты
- Не менять логику, виджеты, импорты — ТОЛЬКО строковые литералы (decode-замена) + тест.
- Не трогать `unified_booking_screen.dart`, `root_shell.dart` (другой агент их правит прямо сейчас — UI-срез).
- Без новых зависимостей; без bump версии; без релиза.

## Критерии приёмки
- Ни одной CP1251/CP1252-сигнатуры в `lib/` (сканер зелёный); расширенный `mojibake_scan_test` падает на вставленной сигнатуре (самопроверка).
- analyze 0 ошибок, тесты зелёные; коммит(ы), push (pull --rebase БЕЗ --autostash, чистое дерево).
- Отчёт до 20 строк: список файлов/строк (что→что), сколько литералов исправино, analyze/test, хеши.
