# ТЗ: исправление двойной кодировки (mojibake) в трёх файлах

Статус: **выдано** (senior)
Дата: 31.10.2026

## Цель
Восстановить корректные кириллические строки в файлах, повреждённых double-UTF-8 (UTF-8-байты, прочитанные как CP1252, и записанные обратно). Пример: «Отмена» сейчас выглядит как «РћС‚РјРµРЅР°».

## Файлы (только они + один новый тест)
- `lib/state/masters_store.dart`
- `lib/features/money/money_screen.dart`
- `lib/features/jobs/job_detail_screen.dart`
- Новый: `test/mojibake_scan_test.dart`

## Что входит
1. Починить ВСЕ повреждённые строки в этих трёх файлах (лiterals, комментарии не обязательны, но если рядом — починить). Повреждения: подписи UI, placeholder'ы, error-сообщения (ArgumentError/StateError/FormatException), дефолтные названия счетов и категорий, шапки Excel-импорта ('название','тип','категория','сумма','счёт', 'направление'… — важно! от них зависит импорт), «Сшт» (unit default), символы ₽ и тире (сейчас «в‚Ѕ», «вЂ”»).
2. Восстанавливать ТОЧНОЕ исходное написание: свериться с историей `git log -p` / `git show` до повреждающего коммита (найти его: `git log --all -S 'РћС‚РјРµРЅР°' -- lib/features/money/money_screen.dart` и аналогично для остальных файлов). Сохранить в отчёте список вводящих коммитов.
3. **Не менять** логику, имена методов, схемы, поведение. Только строки.
4. Regression-тест `test/mojibake_scan_test.dart`: читать все `lib/**/*.dart`, фэйлить при нахождении сигнатур двойной кодировки (список: 'Р°','Рѕ','С‚','СЏ','С€','Рџ','Рї','вЂ','в‚','Ѕ','СЃ' — уточнить/расширить по факту; сигнатуры — пары «кириллица+редкий символ», встречающиеся только в CP1252-mojibake). Тест должен находить текущее повреждение в git-History-версиях, если подставить — то есть работать как guard.
5. Проверка, что других файлов не затронуто (по факту аудит: lib/app, core, data, features/{booking,clients,employees,inventory,more,onboarding,settings,stats,today}, jobs_screen, job_form, cost_calculator — чистые; перепроверить).

## Критерии приёмки
- `grep -r 'Р°|Рѕ|С‚|СЏ|вЂ' lib/` — пусто.
- Пятны: «Отмена», «Готово», «Быстрая продажа», «Смена кассы», «Всего на счетах», «Налоговый резерв», «Регулярные платежи», «Наличные», «Перевод», «Оплата заказа», «Закупка у поставщика», «₽», «—» — читаются нормально.
- Excel-импорт-шапки совпадают с документацией/экселем (проверить `masters_store.dart` import-методы и любые тесты/доки про шаблон).
- `flutter analyze --no-pub` 0 ошибок; `flutter test` — зелёно (включая новый scan-тест).
- Commit `Fix double-encoded Cyrillic strings (mojibake) in store and screens`, push main. В отчёте: список файлов, число изменённых строк, вводящие коммиты, результаты.

## Запреты
- Не менять зависимости, схему БД, логику.
- Не трогать `windows/flutter/generated_*`.
- Не публиковать релиз в этой задаче.
