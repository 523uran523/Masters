# ТЗ: Налоговые профили по странам (tax-profiles)

Статус: **выдано** (senior)
Дата: 01.11.2026
Пользователь: «Налоговые профили по странам (сейчас один процент в настройках)».

## Цель
Заменить один `taxRate` в настройках на **набор налоговых профилей по странам**: несколько профилей (страна/режим + ставка), активный профиль определяет ставку налога, используемую в приложении (резерв в Today, документы, статистика).

## Входит
### А. Данные (SharedPreferences, без БД-миграции)
- `settings_controller.dart`:
  - `taxProfiles` — список профилей: `[{id, country, name, rate}]` (rate — проценты 0–100).
  - `activeTaxProfileId` — id активного профиля.
  - Пресеты стран (по умолчанию при создании): RU «Самозанятость 4%», RU «Самозанятость 6%», KZ «Самозанятый (0-2% по обороту — фиксированная ставка)», US «Sole prop (0%)» — минимальный набор, редактируемый.
  - `getActiveTaxRate()` — rate активного профиля (0, если нет профилей/не активен).
  - Обратная совместимость: если старый `taxRate` задан и профилей нет — не сломать (показать как есть; не дублировать).

### Б. UI (settings_screen, блок «Деньги»)
- В блок «Деньги» (уже существует) добавить карточку «Налоговые профили»:
  - Список профилей: имя/страна + ставка + переключатель «активен».
  - Кнопка «Добавить профиль» → диалог (страна, имя, ставка %).
  - Изменение ставки/имени — инлайн или диалог.
  - Удаление профиля (кроме активного — нельзя или предупреждение).
- Убрать старый одиночный ввод `taxRate` из настроек (или оставить скрытым — по вкусу, но в UI не дублировать с профилем).

### В. Точки использования
- Во всех местах, где сейчас читается `settings.taxRate` (grep по `taxRate|Налоговый резерв|tax reserve`):
  - `today_screen.dart` (налоговый резерв в сводке),
  - `stats_screen.dart` (если есть),
  - `document_service.dart` / `document` (счета, PDF — ставка в документах),
  - `money_screen.dart` (если есть).
  заменить на `settings.getActiveTaxRate()`.
