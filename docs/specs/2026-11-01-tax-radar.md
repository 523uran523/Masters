# ТЗ: Налоговый радар НПД (НПД лимит 2.4М ₽ в год) (tax-radar)

Статус: **выдано** (senior)
Дата: 02.11.2026
Пользователь: «Налоговый радар (НПД лимит 2.4М ₽ в год): индикатор в настройках и на Сегодня (налоговый резерв / название профиль). Хочешь?» → «делай это».

## Цель
Ввести **Налоговый радар (НПД)** — индикатор годового дохода по счётам до жёсткого лимита (по умолчанию 2 400 000 ₽/год):
- Прогресс-бар дохода за текущий год от лимита.
- Оставшаяся сумма до лимита.
- Цветовое кодирование: зелёный < 80%, жёлтый 80–95%, красный ≥ 95%.
- Предупреждающие тексты при приближении к лимиту.
- Размещать индикатор (а) в настройках (блок «Деньги» рядом с налоговым профилем) и (б) на Today (в карточке-сводке).

Для профилей, не относящихся к НПД (УСН, без налога), лимит отключается — показывать просто резерв.

## Входит
### A. Настройки лимита
- `settings_controller.dart`: новый ключ `tax_income_limit_cents` (int, дефолт `2_400_000 * 100 = 240_000_000`). Геттер `taxIncomeLimitCents`, сеттер `setTaxIncomeLimitCents(value)`. Также добавить для профилей новую флаг-опцию `npdLimitApplicable: bool` (по умолчанию `country == 'RU' && name.contains('Самозанятость')`?). Если профиль отмечен как NPD — лимит применяется. Иначе — радар не отрисовывается или показывает только резерв.

  *Примечание*: «профиль + лимит» — возможно, добавить отдельное settings-поле «Применять лимит НПД». Минимум: текст «Налоговый радар работает для профилей НПД; текущий профиль: %s, лимит X»; опция «вкл. радар».

### B. Вычисление годового дохода
- `masters_store.dart`: добавить метод `annualIncomeCents({int? year})` — сумма `amountCents` всех транзакций с `direction == 'in'` и `!voided` за указанный год (по умолч. `DateTime.now().year`). Лучше сразу вычислять при вызове (по `moneyTransactions`), без кеширования (данных немного).
- Также `annualIncomeNpdLimitProgress()` = `annualIncomeCents / taxIncomeLimitCents` (0..1+, clamped).
- `annualIncomeLeftCents()` = `taxIncomeLimitCents - annualIncomeCents` (clamped ≥ 0).

### C. UI — Today (`today_screen.dart`)
В карточке сводки (или отдельно под ней) — компактный блок-батарея:
- "Налоговый радар (НПД): X% из лимита 2,4М"
- Linear horizontal progress bar (цвет по порогам)
- Под ним: "до лимита: Z ₽" + мелкий текст при ≥80%.

Если налоговый профиль не-НПД — показать только «Налоговый резерв: … ₽ ({rate}%)» (как сейчас).

### D. UI — Money (`money_screen.dart`)
В сводке дня/месяца (или отдельная карточка сверху) — прогресс-бар annual + "Лимит: X/2,4M ₽". Tap → детальная панель с разбором по месяцам? — простой «Доходы по месяцам» список (12 строк). **Не обязательная depth**, но желательна: суммы по месяцам (доходы/расходы).

### E. UI — Settings (настройки)
- В блок «Деньги» → под блоком «Налоговые профили» новая карточка «Налоговый радар (НПД)»:
    - Toggle: «Учитывать лимит НПД (2,4M/год)».
    - Поле «Лимит дохода, ₽» editable.
    - Прогресс-бар текущего года ( аналог Today).
    - Текст «Внимание: при превышении 2,4M ₽ зарегистрируйтесь как ИП или измените налоговую схему.»
