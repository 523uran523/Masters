# Вход в Яндекс без логина и пароля

Приложение больше не хранит логин и пароль Яндекс Диска. Вход выполняется
в браузере на стороне Яндекса, а приложение получает только OAuth-токен
(и refresh-токен для продления). Пароль, 2FA и подтверждения остаются
на сайте Яндекса.

## Как это работает

1. Кнопка «Войти через Яндекс» открывает страницу `oauth.yandex.ru` с PKCE-запросом.
2. Пользователь вводит пароль на сайте Яндекса (приложение его не видит).
3. Яндекс возвращает приложение по адресу `http://localhost:8080/oauth/yandex?code=...`.
4. Приложение обменивает код на токен через локальный сервер (обход CORS) и
   сохраняет только токен. Код из адресной строки сразу убирается.

На Android/Windows тот же вход работает через страницу с кодом
(`https://oauth.yandex.ru/verification_code`): код показывается в браузере и
вводится в приложении.

## Что нужно сделать один раз

1. Открыть <https://oauth.yandex.ru/client/new> и создать приложение:
   - Платформа: **Веб-сервисы**.
   - Redirect URI (добавить оба):
     - `http://localhost:8080/oauth/yandex`
     - `https://oauth.yandex.ru/verification_code`
   - Доступ к API: **Яндекс Диск** → чтение и запись
     (`cloud_api:disk.read`, `cloud_api:disk.write`).
2. Скопировать **ClientID** (и **Client secret**, если Яндекс его выдал —
   для веб-приложений он обычно нужен для обмена кода на токен).
3. Собрать проект с этим ClientID:

```bat
set YANDEX_CLIENT_ID=ваш_client_id
flutter build web --release --no-web-resources-cdn --no-wasm-dry-run --dart-define=YANDEX_CLIENT_ID=%YANDEX_CLIENT_ID%
```

Секрет приложения **не попадает в браузер**: web-сборка отправляет обмен
кода на `/api/oauth/token`, а локальный сервер добавляет `client_secret`
из переменной окружения `YANDEX_CLIENT_SECRET`:

```bat
set YANDEX_CLIENT_SECRET=ваш_client_secret
```

`launch_masters.bat` подхватывает обе переменные окружения автоматически,
поэтому достаточно задать их перед запуском ярлыка (или прописать
`set YANDEX_CLIENT_ID=...` / `set YANDEX_CLIENT_SECRET=...` в начало bat-файла).

Для Android/Windows (сборка напрямую, без локального сервера) секрет
передаётся в приложение через `--dart-define=YANDEX_CLIENT_SECRET=...`.
Это компромисс: в мобильном/десктопном бинарнике секрет извлекаем, поэтому
для продакшена лучше вынести обмен токена на свой backend.

## Ограничения

- Redirect URI привязан к порту `8080`. Если менять порт сервера, нужно
  обновить и `_webRedirect` в `lib/core/yandex_oauth.dart`, и настройки
  приложения в Яндексе.
- Токен хранится локально (shared_preferences) и продлевается автоматически
  через refresh-токен. Кнопка «Отключить» удаляет токены с устройства;
  файлы на Диске остаются.
- Бэкап лежит в `disk:/Masters/masters-backup-latest.json` — тот же файл
  используют веб-версия и Android-приложение.
