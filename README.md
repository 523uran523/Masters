# Masters

Локальный трекер для мастера/бригады: клиенты, объекты, заказы/наряды, этапы работ, материалы, учёт времени, итоги.

## Стек
Flutter 3.47 / Dart 3.13, CupertinoApp, provider, sqflite (+FFI), shared_preferences.

## Платформы
- **Android/iOS** — мобильное приложение
- **Windows** — десктопное приложение
- **Web** — браузерная версия с локальным сервером

## Оффлайн-first и мобильный APK

- Мобильный APK работает локально (SQLite, без интернета): заказы, деньги, склад, зарплата.
- Автообновление через сервер: проверка версии, скачивание APK, проверка SHA-256, установка.
- Вложения к заказам: файлы (фото/документы) привязываются к заказу (job_attachments, БД v19).
- Быстрое создание записи: из карточки клиента можно сразу создать запись с конфликт-проверкой по ресурсу/времени.

## Быстрый запуск Web-версии

### Для пользователя
1. Найдите на **Рабочем столе** ярлык **"Masters Web"**
2. Дважды кликните по нему
3. Приложение откроется в браузере

При первом запуске сборка займёт 1-2 минуты. Последующие запуски — мгновенные.

**Остановка:** Закройте окно консоли с сервером.

## Разработка

### Мобильное/десктопное
```bash
flutter pub get
flutter run
```

### Web-версия (ручной запуск)
```bash
cd Masters
.\launch_masters.bat
```

## Сборка

### Android
```bash
flutter build apk --release
```

### Windows
```bash
flutter build windows --release
```

### Web
```bash
flutter build web --release --no-web-resources-cdn
```

## Архитектура Web-версии

**Файловая структура:**
```
Masters/
├── launch_masters.bat         # Единый скрипт запуска (используется ярлыком)
├── web_server/
│   └── server.dart            # HTTP-сервер на Dart
├── build/web/                 # Скомпилированное web-приложение
└── web/                       # Исходники (index.html, manifest, иконки)
```

**Локальный сервер:**
- Порт: 8080
- Хост: localhost (127.0.0.1)
- Автоматическая сборка при первом запуске
- Проверка занятости порта
- SPA routing для Flutter web

**Отличия от мобильной версии:**
- IndexedDB вместо SQLite (автоматическая замена)
- Нет push-уведомлений (ограничения браузера)
- Нет фоновой работы
- Экспорт/импорт через загрузку файлов
