# Masters

Локальный трекер для мастера/бригады: клиенты, объекты, заказы/наряды, этапы работ, материалы, учёт времени, итоги.

## Стек
Flutter 3.47 / Dart 3.13, CupertinoApp, provider, sqflite (+FFI), shared_preferences.

## Запуск
```bash
flutter pub get
flutter run
```

## Сборка
```bash
flutter build apk --release
```
